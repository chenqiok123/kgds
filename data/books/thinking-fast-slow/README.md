## 脚本结构规范（村长约束的操作化）

每期五段，全文约1000字（听读约5分钟）：

| 段 | 时长 | 纪律 |
|---|---|---|
| 【开场钩子】 | ~1min | 生活场景/现象切入，**不提保险** |
| 【书中精读】 | ~2.5min | 概念内核+卡尼曼的实验/案例（内容主体） |
| 【回声】 | ~30s | **提及而非硬塞**：≤2句话，像镜子照一下保险世界即收。禁词：产品名/保费/保额/买保险；句式=陈述现象+留白 |
| 【敲重点】 | ~30s | 明牌考点，锚定大师擂台对应题 |
| 【金句海报】 | — | 3条备选（格言体/比喻体/反差体），供代理人选用或关键词触发生成 |

## 金句海报机制

- 每期3条预定金句，代理人择一；或输入关键词→AI按风格库生成
- 海报文案位：`我在《思考，快与慢》的「{概念名}」— {金句} — {代理人署名}`
- 双版本：成就版（无名片）/ 展业版（+姓名+执业证号，走营销合规）
- 调性铁律：智识感、不油腻、不发保险味，但保险人发出来恰如其分
